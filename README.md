# 📌 Project Overview

Managing daily income and expenses manually often becomes tedious and error-prone. This project simplifies personal cash management by combining automated financial tracking with AI-powered analysis.

The application allows users to:

- Enter account information.
- Generate and manage daily financial transactions.
- Automatically compute the running balance after every transaction.
- Visualize spending patterns.
- Receive intelligent financial summaries generated by Groq's Llama 3.3 70B model.

Instead of reading large spreadsheets, users receive a concise dashboard with meaningful insights about their financial health.

# 📄 Detailed Module Explanation

## 1. app.py

The main application file.

Responsibilities:

- Initializes Streamlit pages
- Sidebar navigation
- User account setup
- Dashboard rendering
- Calls every supporting module

---

## 2. ai_agent.py

Handles communication with Groq Cloud.

Responsibilities:

- Reads API key
- Creates prompts
- Sends requests to Groq
- Receives AI-generated financial summaries

Model Used:

```
llama-3.3-70b-versatile
```

Responsible for all financial calculations.

Functions include:

- Generate daily transactions
- Income calculation
- Expense calculation
- Opening balance
- Closing balance

- Transaction sorting

Contains reusable dashboard components.

Includes:

- Digital bank card

- Expense donut chart
- Transaction tables
- Dashboard styling

---

## 5. config.py

Stores global application settings.

Includes:

- Page configuration
- CSS styling
- Theme settings
- Environment variable loading

# 💹 Running Balance Calculation

The running balance is computed sequentially after each transaction.

Formula:

```text
New Balance = Previous Balance + Credit − Debit
```

Example:

Initial Balance

```
₹30,000
```

Transactions

```
+ Salary      ₹15,000
- Grocery      ₹1,200
- Fuel           ₹800
+ Refund       ₹2,000
```

Running Balance

```
30,000

45,000

43,800

43,000

45,000
```

# 🚀 Setup & Installation

## 1. Clone Repository

```bash
git clone https://github.com/your-username/daily-cash-summary-agent.git
```

```bash
cd daily-cash-summary-agent
```

---

## 2. Install Dependencies

```bash
pip install -r requirements.txt
```

---

## 3. Create Environment File

Create a `.env` file inside the project folder.

```env
GROQ_API_KEY=your_actual_groq_api_key_here
```

---

## 4. Run the Application

```bash
streamlit run app.py
```
